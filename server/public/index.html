Pre-Design Research · 案例研究

建筑案例研究 Agent

上传或粘贴一份建筑设计任务书。Agent 将解析关键词、检索案例、提取图片、归纳设计策略，生成 11 页前期研究汇报。点击生成后，正文会发送给部署方配置的 AI 平台。持有报告链接的人可以查看内容，请使用可外发的项目资料。

DOCX、文字版 PDF、TXT、MD · 最大 10 MB

Agent Workflow · 工作流

  1. 解析任务书，提取功能 / 规模 / 场地 / 风格关键词
  2. 调用 web_search 检索 4 个相关建筑案例（ArchDaily / 谷德 / Dezeen）
  3. web_fetch 每个项目页，提取图片 URL 和元数据
  4. 为每个案例生成结构化分析（概念 / 材料 / 空间）
  5. 合成 5 个设计指向：场地 / 形式 / 空间 / 材料 / 运营
  6. 套模板生成 HTML，呈现为可翻页 deck

Output · 输出

11 页 HTML 演示文稿：封面 + 4 个案例页（含图片轮播）+ 横向对比表 + 5 页设计指向。
