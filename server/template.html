Brief Abstract · 任务书摘要

浙南松阳县四都乡陈家铺村，利用废弃村小学进行改造与扩建，整合阅览、展陈、多功能厅、村民活动、艺术家驻留五类功能。场地位于海拔 850m 山脊古村，面向梯田与晨雾。设计需在本地材料、成本约束与传统风貌之间，寻找一种克制的当代性。

Key Requirements · 核心要求
  • 废弃村小学改造 + 扩建
  • 1,500 ㎡ 公共文化综合体
  • 山脊崖居古村 · 850m
  • 本地石 / 木 / 夯土为主
  • 成本 ≤ 3,500 元/㎡
  • 公共性 · 在地性 · 轻度当代

场地回应

Site Response
Takeaway 01 / 05
Lesson · 案例启示

四个项目的共同态度——最小干预、最大在场。Liyuan 消解于山林、Chenjiapu 外壳完全保留、Xiadi 以残墙为容器、Pingtian 延续院落秩序。建筑不宣告自己，而是让场地继续说话。

Direction · 本项目指向

原村小学夯土主体 100% 保留。900 ㎡ 新建部分藏于场地后坡，从主街巷立面不可见；建筑的"正面"朝东，面对梯田与晨雾——把场地最珍贵的取景权交给空间。

形式操作

Formal Move
Takeaway 02 / 05
Lesson · 案例启示

"壳体 + 内核"是这一类乡村公共建筑的普遍策略——外形不动，内部重写。Chenjiapu 与 Xiadi 是最极端形态；体量始终保持坡顶木构民居的轮廓与尺度，不做当代"地标"。

Direction · 本项目指向

保留夯土双坡外壳与原尺度。新建部分以 2–3 个小体量群落沿坡地跌落接入，避免单一大体量破坏村落肌理；坡屋顶方向与邻近民居对齐。

空间氛围

Spatial Atmosphere
Takeaway 03 / 05
Lesson · 案例启示

外部克制换取内部戏剧性。Liyuan 的阶梯阅读剧场、Chenjiapu 的三层悬浮阁楼、Pingtian 的通高院落——都把叙事收进内部，让访客进入后才被打动。

Direction · 本项目指向

阅览厅借 Liyuan + Chenjiapu 的阶梯/台地语汇构成垂直阅读剧场；多功能厅借 Pingtian 的通高院落策略；艺术家工作室保持简朴，形成公共—私密的节奏对比。

材料逻辑

Material Logic
Takeaway 04 / 05
Lesson · 案例启示

本地材料不是装饰，是叙事主角。Liyuan 柴薪、Pingtian 夯土、Xiadi 木纹混凝土——当代材料也必须"说本地语言"，而不是贴一层假壳伪装。

Direction · 本项目指向

原夯土墙 100% 保留并修复。新建部分采用本地木构 + 碳化松木模板混凝土（参照 Xiadi）；石材仅用于基础与铺地——禁止装饰性石贴面。

运营策略

Operational Strategy
Takeaway 05 / 05
Lesson · 案例启示

Chenjiapu 已验证陈家铺村的村民 + 游客混合客流可持续（2021 年营业额 150 万）。单一书店已是成熟锚点——文化驿站需要差异化切入，而不是重复供给。

Direction · 本项目指向

错峰共享制：白天阅览室属村民，晚上属驻村艺术家；咖啡厅作游客消费锚点；艺术家驻留轮替构成稳定"活"的使用主体——三类人群互不干扰又彼此供养。
